# Task 4：思考题

## 1. Make 和简单的 build.sh 有什么区别？

build.sh是顺序执行脚本，会把所有gcc命令执行一遍，全部重新编译，速度慢
make具备增量编译，只编译被修改过的文件和依赖它的文件，节省时间
    还支持依赖关系自动管理，伪目标，并行编译，依赖检查机制

## 2. CMake 是编译器吗？

执行 `cmake --build build` 时，最终是谁在编译 C 源文件？

CMake不是编译器，是构建系统生成工具。是gcc在编译

## 3. 为什么不希望每次都重新编译所有 `.c` 文件？

全部重编耗时长,效率低
若重编未修改的源码，编译出的目标文件.o不变，无用处
