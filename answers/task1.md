# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。
1.预处理（gcc -E）:读取C源码，用#include加入头文件，用#define定义宏常量，进行条件编译指令，裁剪代码，删除注释（生成.i文本）
2.编译（gcc -S）对预处理之后的代码进行语法和语义错误检查，将C代码转成汇编代码（.s文件）
3.汇编（gcc -c）汇编器把汇编语言翻译成机器指令，生成目标文件（.o文件），为二进制
4.链接器把多个.o目标文件和系统库合并，解析符号，补全缺失的函数地址，解决符号引用，生成可执行文件。
补充：源文件hello.c+预处理器和头文件==hello.i+编译器==hello.s（汇编语言写的）+汇编器==hello.o（二进制）+printf.o==hello(可执行文件)
